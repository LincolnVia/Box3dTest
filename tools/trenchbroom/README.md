# TrenchBroom

Set the TrenchBroom game path to the project root (the directory containing `resources/` and `tools/`). Use the `Box3dTest` game configuration from `tools/trenchbroom/Box3dTest/GameConfig.cfg`.

Run the `Compile` profile to build the BSP and launch Box3D. The profile uses the included macOS ericw-tools binaries under `tools/trenchbroom/ericw-tools/`.
